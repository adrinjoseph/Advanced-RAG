# Contributing

Contributions are welcome! Please follow these guidelines:

1. **Branch Naming**: Use descriptive branch names (e.g., `feature/ingestion-pipeline`, `fix/retrieval-filter`).
2. **Conventional Commits**: Write clear commit messages conforming to conventional commits (`feat:`, `fix:`, `docs:`, `refactor:`, `test:`).
3. **Quality Gates**: Ensure Ruff linting, formatting checks, and pytest unit tests pass locally before opening a pull request.
4. **No Invented Numbers**: Never commit unmeasured benchmark numbers or claims.
